# Dhruv Tara

## AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Users

Dhruv Tara is an AI-based cognitive gaming and memory assistance platform designed for elderly users, with a focus on accessibility, personalization, familiar interactions, adaptive cognitive activities, and caregiver support.

The platform combines cognitive games, memory assistance, familiar voice interaction, personalized content, adaptive difficulty, passive interaction analysis, and a caregiver dashboard into a single elderly-friendly application.

---

## Overview

Elderly users may face difficulties with remembering people and familiar information, following daily routines, staying cognitively engaged, and interacting with complex digital applications.

Dhruv Tara addresses these challenges through a simple and personalized interface.

Instead of treating cognitive support as a separate test, Dhruv Tara integrates cognitive activities into everyday interaction.

The platform allows an elderly user to:

- Navigate the application using simple controls and voice commands
- Interact with familiar people and memories
- View daily activities and reminders
- Access calming and familiar content
- Play different cognitive games
- Interact with a familiar voice assistant
- Receive adaptive game difficulty based on interaction history

Caregivers can access detailed task-level observations through a separate dashboard.

---

## Problem Statement

Elderly users, particularly those experiencing memory and cognitive difficulties, may face challenges such as:

- Difficulty remembering people and familiar information
- Difficulty following daily routines
- Reduced cognitive engagement
- Difficulty using complicated digital interfaces
- Difficulty remembering everyday objects and activities
- Limited access to personalized digital assistance

Many existing systems separate cognitive assessment from everyday interaction.

Dhruv Tara follows a different approach by integrating assistance, personalization, cognitive activities, and interaction monitoring into one platform.
